## Key deadlines and logistics

- **Submission deadline:** Sunday, July 26th 2026 at **09:00 am WEST**. Late submissions not accepted.
- **Teams:** Up to **5 people**. Each member must be accepted and stake individually. Solo is fine.
- **Stake:** Refundable ETH stake required to confirm attendance. Returned after you submit a project (typically ~2–3 weeks post-event). Hardship exceptions: contact [hello@ethglobal.com](mailto:hello@ethglobal.com).
- **Partner prizes at submission:** Select up to **3 Partner Prizes**. If a partner has multiple tracks, you can be eligible for all of them while counting as 1 Partner Prize selection.
- **Demo video:** Optional but strongly encouraged; **2–4 minutes**, min **720p**. Featured on ETHGlobal Showcase.
- **Finalist judging:** 7 minutes total (4 min demo + 3 min Q&A).
- **Partner booth presenting:** Optional for networking/feedback; partners judge from submission materials (check partner-specific rules for exceptions, e.g. ENS requires Sunday morning booth presentation).



### Tracks

1. **Classic ("From Scratch")** — Project must start during the hackathon. Public libraries / boilerplates OK. Pre-existing project-specific code disqualifies partner prizes and Finalist category.
2. **Continuity** (e.g. Extend Open Source / Ship a Feature) — Build on an existing codebase. Document pre-existing work; judging focuses on new work during the hackathon window. Several partner prizes are Continuity-only (marked below).



### Judging criteria (Finalist)

Technicality · Originality · Practicality · Usability (UI/UX/DX) · WOW Factor

### AI tool policy

AI tools (ChatGPT, Claude Code, Copilot, Cursor, etc.) are permitted with attribution. Document where AI was used. AI should assist, not wholly create the project. Spec-driven workflows OK if you include all specs/prompts/planning artifacts in the repo.

### Version control

Proper git history required. Large single commits / missing history can disqualify.
